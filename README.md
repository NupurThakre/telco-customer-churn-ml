# Telco Customer Churn — ML Project

## Objective
Predict customer churn probability and prioritize retention efforts.

## Approach
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Logistic Regression (validation)
- XGBoost (final model)
- Lift-based business evaluation

## Notebooks
- 01_EDA_&_Validation.ipynb  
- 02_Feature_Engg_&_Modeling.ipynb  

## Key Result
Top 10% high-risk customers capture ~3× more churners than random selection.

## Tools
Python, Pandas, Scikit-learn, XGBoost
